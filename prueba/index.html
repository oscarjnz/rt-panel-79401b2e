Probar conexiones

Comprueba desde esta tablet qué servicios externos responden. Cada prueba pide un dato real a la API desde la propia página, que es lo que haría un widget de clima, divisas o criptomonedas.

Cómo leer el resultado. OK: la API respondió y el widget puede usarla. ERROR: no se pudo leer la respuesta. Como Internet Explorer no distingue entre un fallo de cifrado (TLS) y un permiso del sitio (CORS), usa el enlace "abrir directo" de esa fila: si la dirección abre y muestra texto, el cifrado funciona y el problema sería el permiso del sitio; si IE muestra un error de seguridad o de conexión, es el cifrado.
